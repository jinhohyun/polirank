## 1. 프로젝트 개요 (Overview)
**PoliRank**는 정파적 감정이나 단순 호불호에 휘둘리지 않고, **100% 국회 공공데이터 및 의정활동 팩트**에 기반하여 국회의원의 능력치를 객관화·수치화하고 실시간 랭킹을 제공하는 차세대 정치 데이터 & 참여 플랫폼입니다.

---

## 2. 핵심 기능 및 업그레이드 내역 (Key Features v1.1)

### 📊 1. 객관적 팩트 기반 6대 정량 지표 수치화 랭킹
기존 4개 지표에서 국회 전자표결 및 회의록 속기록 팩트를 추가하여 **6대 핵심 지표**로 확장했습니다:
1. **📜 입법 실적 (25% 가중치)**: 대표발의(25점) + 공동발의(6점)
2. **🎯 법안 가결 성과 (25% 가중치)**: 본회의 가결(55점) + 상임위 소위 통과(25점)
3. **⏰ 의정 출석 성실도 (20% 가중치)**: 본회의/상임위 출석률 및 무단결석/징계 감점
4. **🗳️ 본회의 안건 표결 참여율 (15% 가중치)**: 국회 본회의 전자투표 안건 표결 참여율 (%) (공공데이터 100%)
5. **🎙️ 상임위 속기록 발언력 (10% 가중치)**: 국회 회의록 속기록상 실제 정책 질의/발언 빈도
6. **💡 정책 세미나/공청회 (5% 가중치)**: 정책 세미나/공청회 주최 및 대정부 질문
- **종합 PoliScore** = `0.25*입법 + 0.25*가결 + 0.20*출석 + 0.15*표결 + 0.10*발언 + 0.05*세미나`
- **의원 티어 뱃지**: `S+`(90점 이상 최우수), `S`(80점 이상), `A`(70점 이상), `B`(60점 이상), `C`(분발 요망)

### 🎨 2. 캐리커쳐 디테일 강화 & 3D 플립 공식 실사진 원터치 전환
- 각 의원의 고유 인상(이준석의 2:8 스마트 가르마, 정청래의 굵은 뿔테, 박찬대의 온화한 안경, 박지원의 연륜 백발과 눈가 주름, 여성 의원의 정갈한 헤어스타일 등)을 정교하게 반영
- 카드 내 아바타를 클릭하면 **3D 회전 애니메이션과 함께 국회 공식 고화질 프로필 사진으로 즉시 플립(Flip) 전환**

### 🎈 3. 프로필 재미 요소 (Fun Factors) 완비
- **🔥 최근 30일 언론 언급 횟수**: 포털/빅카인즈 뉴스 언급 건수 (예: "언론 언급 3,420회 🔥")
- **💬 시그니처 대표 어록 한 줄**: 32인 전수 대표 어록 말풍선 수록
- **🏷️ 시그니처 키워드 태그**: 각 의원별 고유 해시태그 3개 배치 (`#원내대표`, `#사이다정치`, `#쇄빙선` 등)

### 💖 4. 커뮤니티 & 참여 기능
- **1클릭 실시간 응원하기**: 클릭 시 통통 튀는 플로팅 하트 파티클 및 SQLite DB 실시간 반영
- **시민 한줄 토론 피드**: 스탠스(`💖 응원` / `💡 제언` / `🧐 분발`) 선택 및 댓글 피드
- **정치후원 연계**: 선관위 `give.go.kr` 공식 링크 및 공식 후원계좌 **원클릭 1초 복사**


- API 대화형 문서: **http://localhost:8000/docs**

